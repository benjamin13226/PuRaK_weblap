[ Magyar | English ]

## 🇭🇺 Magyar

### 📻 A Projektről
Ez a projekt a **HA5KHC Puskás Tivadar Rádióklub** számára készülő hivatalos, modern és teljesen dinamikus weboldal, amelyet szabadidőmben, önkéntes alapon fejlesztek. 

A rádióklub korábbi, statikus weboldala mára elavult, ezért egy rugalmasabb, könnyen szerkeszthető és bővíthető megoldásra volt szükség. Az új platform segítségével a klubtagok és az érdeklődők könnyen elérik a friss híreket, dokumentumokat, galériákat és a különböző szakosztályok információit.

### 🛠️ Technológiai Háttér
* **Backend / CMS:** Python, Django, Wagtail CMS
* **Adatbázis:** SQLite (fejlesztés alatt)
* **Konténerizáció:** Docker
* **Frontend:** HTML5, CSS3, JavaScript

### 📈 Projekt Státusz és Fejlődés (Progress)
A projekt fejlesztése iteratívan halad, figyelembe véve a korábbi verzió tanulságait (teljes újrakezdés a rugalmasabb szerkeszthetőség érdekében):

* ✅ **Kezdeti beállítás (Initial Wagtail project setup):** Alapstruktúra és keretrendszer felépítése.
* ✅ **Újrakezdés és architektúra váltás:** Az elavult statikus megközelítés elvetése, átállás egy dinamikus, Wagtail CMS alapú szerkeszthető rendszerre.
* ✅ **Főoldal generálása:** Dinamikus főoldal kialakítása a klub arculatához igazodva.
* ✅ **Alapvető modulok integrálása:**
  * Menüszerkezet kialakítása
  * Alap weboldal sablonok (template-ek) létrehozása
  * Kétnyelvű (Magyar - Angol / HU-EN) integráció
* 🔄 **V1.1 Státusz (Jelenlegi):** Nagyjából minden szinten működő, stabil alapokon álló oldal, folyamatos finomítás alatt.

## 🇬🇧 English

### 📻 About the Project
This project is the official, modern, and fully dynamic website for the **HA5KHC Puskás Tivadar Radio Club**, developed voluntarily in my spare time. 

The club's previous static website became outdated, prompting the need for a more flexible, easily editable, and scalable solution. The new platform allows club members and visitors to seamlessly access fresh news, documents, galleries, and department-specific information.

### 🛠️ Tech Stack
* **Backend / CMS:** Python, Django, Wagtail CMS
* **Database:** SQLite (during development)
* **Containerization:** Docker
* **Frontend:** HTML5, CSS3, JavaScript

### 📈 Project Status & Progress
The project is being developed iteratively, incorporating lessons learned from previous iterations (a complete fresh start to ensure full editability and dynamic content management):

* ✅ **Initial Wagtail Project Setup:** Establishing the core framework and project structure.
* ✅ **Fresh Start & Architecture Shift:** Discarding the old static approach and transitioning to a dynamic, CMS-driven architecture.
* ✅ **Homepage Generation:** Designing and implementing the main landing page aligned with club branding.
* ✅ **Core Modules Integration:**
  * Navigation menu structure setup
  * Base website templates creation
  * Bilingual (Hungarian - English / HU-EN) support integration
* 🔄 **V1.1 Status (Current):** A mostly functional website with stable core features, undergoing continuous refinement and polish.
